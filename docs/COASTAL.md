# Coastal Base 01

The default flight field is a fictional civilian aerospace test site. It is not a real airfield and it is not for navigation.

The apron, hangars, shore, and peaks are meshes built in the browser. The reference painting is a design target only. It is not a skybox, a ground texture, or a photograph of the playable world. No third-party environment model is included.

Coordinates are metres. +x is east, +y is north, and +z is up. The launch ring is south of the hangars. The aircraft starts on the ground, nose north. The amber mark is the precision pad.

Collision uses the same sphere test as the rest of the 6-DOF model. The maintenance hangar is open on the south face below the roof. The main hangar is a solid volume. A ridge and a west cliff block low flight. The bay is drawn as water, but the simulation ground is a solid surface at the same level as the apron. There is no current, buoyancy, or bathymetry.

Facades, windows, puddles, and snow caps are generated drawings on those meshes. They are not surveyed materials.
